# 🎂 Happy Birthday, Kanyaaa

A personalized interactive birthday website made with **HTML, CSS, and JavaScript**.
Designed as a small digital surprise filled with memories, wishes, music, and little interactive moments. ✨

### ✦ Features

* ⏳ Birthday countdown
* 🔐 Password-protected surprise
* 📖 Interactive secret diary with typing animation
* 🌸 Secret garden with interactive flowers
* 📸 Swipeable Polaroid photo gallery
* 🫧 Interactive floating wishes
* 🎵 Custom background music & favorite song player
* ⭐ Animated stars, balloons, and ambient effects
* 💌 Personalized birthday messages

> Made with a little code, a lot of thoughts, and hopefully a smile. 🤍
